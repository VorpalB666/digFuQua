# digFuQua
Ein digitales Fußballquartett

Das digitale Fußballquartett funktioniert wie ein klassisches Quartett, nur eben digital.
Die Spieler verfügen über sechs Attribute (Größe, Schnelligkeit, Passen, Schießen, Zweikampf, Kondition), mit denen sie sich messen können.

Der Spieler hat die Möglichkeit, mit einem bestehenden Kartenset zu spielen oder selbst neue Karten zu erzeugen.
Es lassen sich Karten manuell oder zufällig erstellen.

Wie im klassischen Quartett werden die Karten zufällig verteilt, der Spieler, der am Zug ist, wählt die Kategorie aus, die verglichen werden soll. Es gewinnt jeweils der höhere Wert. 

Hat ein Spieler alle Karten, hat er das Spiel gewonnen.
